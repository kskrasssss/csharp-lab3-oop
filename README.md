## Про проєкт

Репозиторій містить виконану лабораторну роботу з дисципліни **«<Назва дисципліни>»**.

**Мета роботи:** практичне закріплення навичок роботи з керуючими конструкціями, двовимірними масивами та файловим введенням-виведенням із безпечним керуванням ресурсами, а також вивчення об'єктно-орієнтованого підходу: інкапсуляції, наслідування, поліморфізму, абстрактних класів та інтерфейсів.

## Завдання

### Завдання 1. Матриця оцінок
**Тема:** двовимірні масиви, файловий ввід-вивід, `IDisposable`, `using`.

Програма генерує матрицю оцінок студентів за сесію, записує її у текстовий файл (`MatrixWriter`), зчитує назад (`MatrixReader`) та визначає кількість студентів з незадовільними оцінками та кількість відмінників.

| Клас | Призначення |
|---|---|
| `MatrixWriter` | Запис матриці у файл |
| `MatrixReader` | Зчитування матриці з файлу |

### Завдання 2. Клас «Книга»
**Тема:** інкапсуляція.

Клас `Book` містить 7 приватних полів, властивості, два конструктори та три методи: розрахунок ціни зі знижкою, кількості сторінок, що залишились, та віку книги.

### Завдання 3. Ієрархія «Студент»
**Тема:** наслідування та динамічний поліморфізм.

| Клас | Особливості |
|---|---|
| `Student` | Базовий клас: перехід на наступний курс, стипендія, інформація |
| `ContractStudent` | Перехід залежить від оплати контракту, стипендія завжди 0 грн |
| `PostGraduate` | Додаткове поле «керівник», стипендія завжди 5000 грн |

### Завдання 4. Система «Університет»
**Тема:** абстрактні класи та інтерфейси.

| Елемент | Призначення |
|---|---|
| `Teacher` | Абстрактний базовий клас викладача |
| `Professor` | Похідний клас «Професор» |
| `AssociateProfessor` | Похідний клас «Доцент» |
| `IUniversity` | Інтерфейс з методами `AddTeacher` та `SearchByDepartment` |
| `UniversityImpl` | Клас-сервіс, що реалізує інтерфейс і керує колекцією викладачів |


## Запуск

**Вимоги:** встановлений [.NET SDK](https://dotnet.microsoft.com/download).

```bash
# Клонування репозиторію
git clone https://github.com/kskrasssss/csharp-lab3-oop.git
cd csharp-lab3-oop

# Запуск потрібного завдання
dotnet run --project Task1_Matrix
dotnet run --project Task2_Book
dotnet run --project Task3_Students
dotnet run --project Task4_University
```
